Projects

Smart Thermostat

For my final project, I developed a smart thermostat prototype using a Raspberry Pi and Python.

Project features include:

Temperature and humidity monitoring using an AHT20 sensor.

A 16×2 LCD displaying the date, time, temperature, humidity, and thermostat status.

Three operating states: OFF, HEAT, and COOL.

Push buttons for changing the operating state and adjusting the temperature set point.

Red and blue LEDs to indicate heating and cooling behavior.

Serial communication for sending thermostat data.

This project helped me understand how embedded software interacts with physical hardware and how different components work together to create a functional system.
